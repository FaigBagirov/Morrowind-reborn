# Credits

Third-party work used by this conversion. **Read this before publishing
anything**, because some of it carries an obligation and one obligation here is
a licence condition rather than a courtesy.

## Assets under a licence that requires attribution

The helmet mesh is not ours. It is a downloaded model, converted to Morrowind's
format and retextured to match the rest of the set; the sculpt is somebody

## Assets whose terms have not been checked

Everything else the conversion touches is a *retexture of what the player has
already installed*, not a redistribution: the mod ships generated `.dds` files
and a plugin, and it contains no art from Daedric Lord Armor, Vurt's, Morrowind
Enhanced Textures or any other pack in the load order. Those textures are read
to sample colour and structure, and the originals stay where they are.

That distinction matters if a release is ever assembled. Shipping generated
files derived from someone's textures is a different question from shipping
their textures, and it has not been examined here. **Raise it before
publishing, not after.**

## Bethesda

Morrowind, Tribunal and Bloodmoon are Bethesda's. Nothing in this project
redistributes their content: the masters are read, never modified, and never
included.
